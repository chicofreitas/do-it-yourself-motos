# DO it Yourself for Motocycles

This repository is dedicated to the development of the community version. 

# About the Project

A motorcycle maintenance management application designed to organize and track repairs, maintenance history, service records, and motorcycle-related expenses. The goal is to simplify maintenance management, keep track of upcoming services, and ensure motorcycles remain in optimal condition.

# API docs
